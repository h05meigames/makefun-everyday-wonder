## The line

> The escalator handrail slid ahead of my palm, and for three steps I was holding tomorrow.

A small, concrete, slightly uncanny moment everyone has felt but few
have phrased: on an escalator the rubber handrail runs a little faster
than the steps, so your palm is always being left behind by the very
thing you are holding. The turn — holding tomorrow — makes the ordinary
commute strange in a single read, and it is grounded in two specific
details (the palm, three steps) rather than floating in abstraction.

## How it works

`main.ts` (Node 22, standard library only) writes the line to
`/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`) — one line,
UTF-8, no trailing newline, 89 characters, well within the 1–200
character gate — and prints exactly the same line to stdout. It guards
the length in code points (`[...line].length`) before writing.
